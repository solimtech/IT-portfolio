# IT Support Portfolio Website

A responsive, dark-themed personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and current year
- `assets/` — place your résumé PDF here

## Before publishing
1. Replace `Your Name` in `index.html` with your preferred professional name.
2. Review all experience descriptions and make sure every statement is accurate.
3. Add your actual LinkedIn and GitHub profile URLs.
4. Add your résumé PDF at `assets/resume.pdf` (create the `assets` folder).
5. Complete the three project labs. Replace “Lab idea” with “Completed project” only after finishing each one, and add screenshots or documentation.
6. Check your email and phone number and decide what contact information you want public.
7. Open `index.html` in a browser and test every navigation link and the résumé link.

## Run locally
Double-click `index.html` to open it in a modern browser. No build tools are required.

## Publish with a personal domain
One beginner-friendly route is GitHub Pages with a domain you own:
1. Create or sign in to a GitHub account.
2. Create a public repository named `it-portfolio` (or another name).
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder if using a résumé.
4. In the repository, open **Settings → Pages** and choose the main branch as the publishing source.
5. Follow GitHub's current instructions to add your custom domain in the Pages settings.
6. At your domain registrar, add the DNS records GitHub specifies for your chosen domain. DNS changes can take time to propagate.
7. Enable HTTPS in Pages settings once the domain is verified.

Do not publish private information, passwords, internal company screenshots, or customer/user data. Use screenshots from your own practice lab or redact sensitive details.
