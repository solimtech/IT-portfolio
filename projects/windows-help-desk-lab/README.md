# Windows Help Desk Troubleshooting Lab

**Project type:** Simulated IT support lab  
**Environment:** Windows 11 test machine or virtual machine

## Ticket 001: Slow Computer

- **Ticket ID:** LAB-001
- **Issue:** Computer starts slowly and applications take a long time to open.
- **Priority:** Medium
- **Status:** In Progress

### Symptoms
The computer takes longer than expected to start, and applications are slow to open.

### Diagnostic Steps
1. Open Task Manager using `Ctrl + Shift + Esc`.
2. Review CPU, Memory, and Disk usage.
3. Check Startup apps for unnecessary programs.
4. Check available storage under Settings → System → Storage.
5. Record the findings.

### Root Cause
To be determined after testing.

### Resolution
Apply a fix only after identifying the cause. Restart the computer and verify whether performance improves.

### Prevention
- Review startup applications periodically.
- Keep Windows and applications updated.
- Maintain sufficient free disk space.
- Investigate recurring high resource usage.

### Verification
Record startup behavior and application responsiveness before and after troubleshooting.

### Evidence
Add screenshots of actual diagnostic results, with personal information removed.

### Lessons Learned
Document the confirmed cause, the resolution, and the outcome after testing.
